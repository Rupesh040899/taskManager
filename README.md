# MERN Task Manager App

This repository is a  MERN (MongoDB, Express, React, Node) Task Manager app.

## What this includes
- Backend (Express + Mongoose)
  - CRUD APIs: POST, GET, GET/:id, PUT, DELETE
  - Validation and error handling
- Frontend (React + Vite)
  - Task list, Add task form (title, description, status)
  - Edit and Delete
  - Filter by status (All/Pending/Completed)
- README, .gitignore

## How to run project ##


### Backend
1. `cd backend`
2. `npm install`
3. `npm start`

Default server: http://localhost:5000

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev`
Open: http://localhost:5173
